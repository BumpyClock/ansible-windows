    Applies to the next dictation.

    Microphone boost
    For quiet speech or whispering. 0 is off; try 6 or 12 dB first. Higher boost also raises background noise and can distort louder speech.

    Meetings

    Suggest notes when Teams uses the microphone
    Checks app activity without recording audio. You must click Start to capture a meeting. Calendar access is not used.

    Transcript cleanup

    Sends completed meeting text, never audio, to the service you choose. Original wording is kept.

    Service
    Uses the installed Copilot CLI and its signed-in account. Run copilot login if needed. No fallback to another service or account.
    Model
    Reasoning effort
    Clean up automatically
    Off until you turn it on. Manual cleanup stays available on each meeting.

    Send each new completed meeting transcript to Copilot CLI without asking again?

    Applies to meetings started after you turn this on. Saved meetings are not uploaded automatically.

    Privacy and data

    Applies to supported Windows screenshots and screen sharing. The main window stays visible. Some recorders can still capture protected windows.
